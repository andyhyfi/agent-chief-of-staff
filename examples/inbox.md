# Inbox line format

`<notes>/chief-of-staff/inbox.md`: one line per request, in any order.

`[YYYY-MM-DD] [chat | session | agent] [who asked] the request in one line → [placement: workflow name, weekly line, or card id]`

The placement field stays blank until the chief places the request. The line closes once the work has a card, a weekly-file line, or a workflow.

An agent that needs a login it does not have writes one line and stops:

`[YYYY-MM-DD] agent [profile] needs a login for [site] to finish [card id]`
