# Day list format

`<notes>/chief-of-staff/TODAY.md`: the owner's live list for one day. The chief rewrites it whole when the top item changes. Links use the full path from the notes root.

# Today, [weekday] [YYYY-MM-DD]

## Done

- [item] · [link to the result]

## Working on now

- [the one top priority] · [why it is first]

## Ready for your review

- [item] · [chief-of-staff/ready-for-owner/<file>.md]

## Your own

- [task only the owner can do] · [link to its prep]

## Reminders set

- [time] · [what the reminder says] (one-shot cron job)

## Tomorrow

- [carried item] · [why it carried]

## Agent team (no action from you)

- [card title] · [profile] · [status]

## Parked

- [item the owner paused]
