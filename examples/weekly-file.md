# Weekly file format

`<notes>/weekly/<YYYY>-W<NN>.md`: one file per ISO week. It is the to-do list of record; `TODAY.md` draws from it. The Friday 4:00 PM routine drafts next week's file, and the owner approves it before it becomes the active week.
