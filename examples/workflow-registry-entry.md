# Workflow registry entry format

One entry per workflow in `<notes>/chief-of-staff/workflow-registry.md`. A new workflow is proposed to the owner as the first five lines.

- **name**: what it is called
- **owner**: agent profile or the owner
- **trigger**: what makes it run
- **files**: what it reads and writes
- **done-when**: how you know a run is complete
- **status**: Active / Pilot / Dormant / Needs redesign
- **change log**: one dated line per change
